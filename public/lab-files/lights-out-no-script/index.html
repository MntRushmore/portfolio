How it works

Each lamp is a label for a hidden checkbox, so tapping it ticks a box. A ticked box reveals a plus-shaped patch of yellow over that lamp and its neighbours.

The patches are painted in the difference blend mode, where yellow on yellow makes black. So two patches on one lamp cancel out, which is exactly the flip-flop rule the game needs.

.c5:checked ~ .stage .x5 { opacity: 1 }
.x5 { mix-blend-mode: difference }
/* winning is one long selector */
.c1:checked ~ .c2:not(:checked) ~ … ~ .stage
  .sticker { display: flex }

The win check is a selector that only matches when the right boxes are ticked. The tally is a CSS counter, Reset is a plain form button, the level picker is radio buttons, and this note is a details element.

View the page source to check: there is no script tag. It works in any browser from about 2020 on; the yellow underline on finished levels needs the newer :has() selector.
