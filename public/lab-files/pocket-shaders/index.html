How it works

The box holds a fragment shader: a tiny program the graphics chip runs once for every pixel, every frame. Its only job is to answer "what colour is this pixel?"

There are no shapes or images. The sun is "pixels closer than 0.45 to this point", the stripes come from rounding a number down, and the lava is a sum of "one over distance" for a few moving points.

// the three lines the page adds for you

The byte count is the size of the text in the box, as typed. Each edit is compiled straight away; if it has a mistake, the last working picture keeps running and the error shows underneath.
