How it works

The typeface, Anybody, is a variable font: one file that can be any width from squashed to stretched, and any weight from hairline to black. Every letter here is its own element with its own width setting.

Each letter asks for a width based on how close it is to your pointer. Then every line is balanced so the letters add up to exactly the screen width, so when one letter swells, its neighbours must thin out.

// near the pointer = 1, far away = 0
u = clamp(shift + bump(distance))
letter.style.fontVariationSettings =
  `"wdth" ${50 + 100*u}, "wght" ${380 + 520*u}`
// "shift" is found by bisection, per line,
// until the widths sum to the screen width

The pointer drags the heavy spot on a spring, which is why it wobbles when you stop. On a phone, the tilt button reads the device orientation sensor instead, so the weight rolls to whichever side is lower.
